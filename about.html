About This Project

A simple student registration interface built for an HCI laboratory activity.

This project uses HTML, CSS, and JavaScript to practice designing an interface that is easy to understand, easy to use, and accessible. After it is built, it is checked using Nielsen's 10 Usability Heuristics and improved.

Design goals

  • Clear labels and simple wording
  • Helpful error messages next to each field
  • Visible keyboard focus and readable colors
  • A layout that works on phones and computers
